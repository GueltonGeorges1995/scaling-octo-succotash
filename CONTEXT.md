# Recettes

Un site public de recettes de cuisine en français, dont tout le contenu est rédigé par son unique auteur.

## Langage

### Contenu

**Recette** :
Un plat décrit dans un fichier du dépôt, qui correspond à une page du site.
_À éviter_ : article, fiche, post

**Ingrédient** :
Un élément nécessaire à une Recette, décrit par une quantité, une unité et un nom.
_À éviter_ : composant, produit

**Groupe d'ingrédients** :
Un ensemble nommé d'Ingrédients d'une même Recette, comme « Pour la pâte » ; un même Ingrédient peut figurer dans plusieurs groupes.
_À éviter_ : section, partie

**Portions** :
Le nombre de personnes pour lequel les quantités d'une Recette sont écrites.
_À éviter_ : parts, couverts

**Brouillon** :
Une Recette présente dans le dépôt mais absente du site publié.
_À éviter_ : ébauche, recette privée

### Classement

**Catégorie** :
Le type de plat auquel appartient une Recette ; chaque Recette en a exactement une.
_À éviter_ : rubrique, section, type

**Tag** :
Un qualificatif choisi dans le Référentiel de tags ; une Recette peut en avoir plusieurs.
_À éviter_ : étiquette, mot-clé, label

**Référentiel de tags** :
La liste fermée de tous les Tags autorisés sur le site.
_À éviter_ : liste de tags, taxonomie
